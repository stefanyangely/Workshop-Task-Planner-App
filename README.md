# StudyFlow - Smart Student Task Planner

Aplikasi web untuk mengelola tugas, deadline, jadwal belajar, dan produktivitas mahasiswa.

## Demo

[Buka aplikasi](https://stefanyangely.github.io/Workshop-Task-Planner-App/)

## Fitur

- Dashboard dan statistik
- Manajemen tugas (tambah, edit, hapus, filter, cari)
- Kalender bulanan dan mingguan
- Manajemen mata kuliah
- Pomodoro timer
- Catatan belajar
- Analitik produktivitas
- Mode terang dan gelap

## Teknologi

React, Tailwind CSS, dan LocalStorage
